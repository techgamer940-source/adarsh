# Adarsh Stationary Store — Stationery Shop Frontend

## Run
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown by Next.js.

## Customize
- Products/prices/categories: `src/data/products.ts`
- Main page: `src/app/page.tsx`
- Design: `src/app/globals.css`

## Backend-ready
The UI keeps product data separate and the feedback form has a clean submit boundary. Later, replace the demo submit handler with a POST to a Next.js API route/database and add an admin dashboard.
